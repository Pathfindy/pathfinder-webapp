# Commit 42.2 – Effektkategorie Charakterwerte

- Neue Effektkategorie „Charakterwerte“ im Effekteditor.
- Kategorie „Charakterwerte“ ist im Effektfilter verfügbar.
- Filterbezeichnungen verkürzt:
  - Klassenmerkmale → Klassenmerk.
  - Volksmerkmale → Volksmerk.
- Effekte der Kategorie „Charakterwerte“ sind immer aktiv.
  - Aktivierungshäkchen ist dauerhaft gesetzt und deaktiviert.
  - Ein gespeicherter alter Aktivstatus „aus“ wird beim Laden ignoriert und auf aktiv migriert.
- „Boni nach Nutzereingabe“:
  - Kategorie Charakterwerte: -5 bis +17
  - Standardwert / Ausgangswert: 0
  - alle anderen Kategorien bleiben bei +1 bis +10, Standard +1
- Die Auswahl wird weiterhin charakterbezogen über die bestehenden Effektoptionen gespeichert
  und damit vom bestehenden Charakterexport/-import mitgeführt.
- Version v0.42.2.
