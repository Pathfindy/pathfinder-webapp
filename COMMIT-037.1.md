# Commit 37.1 – Energien widerstehen

- Auswahlfeld enthält jetzt 0 / 10 / 20 / 30.
- Grundwert für neue Einträge ist 0.
- Ist die freie Eingabe leer, wird das Auswahlfeld farblich hervorgehoben.
- Sobald in der freien Eingabe ein Wert steht (auch 0), wird stattdessen dieses Feld hervorgehoben und gewertet.
- Wird die freie Eingabe wieder geleert, gilt und leuchtet wieder das Auswahlfeld.
