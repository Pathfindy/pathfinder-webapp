# Hotfix zu Commit 16

Commit-Message:

`fix(admin): show edit buttons for standard effects`

## Korrekturen

- Bearbeiten-Button wird bei entsperrtem Admin-Modus an Standardeffekten angezeigt.
- Standardeffekte lassen sich im bestehenden Effekteditor öffnen und speichern.
- Standardänderungen werden in den lokalen Admin-Arbeitsstand geschrieben.
- Gespeicherte Admin-Änderungen werden beim Entsperren geladen.
- Beim Sperren zeigt die normale Effektseite wieder die unveränderte Standardliste.
- Standardeffekte erhalten keinen Löschen-Button.
