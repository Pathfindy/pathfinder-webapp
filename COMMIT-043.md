# Commit 43 – Waffenfinesse

Auf Kampf → Angriffe besitzt jeder Angriff in den Details die Option **Waffenfinesse – GE statt ST für Angriff**.

Aktiv:
- entfernt für diesen Angriff den Anteil von `ST: Stärke (Attribut)` → `Angriff Nah`;
- verwendet stattdessen `GE: Geschicklichkeit (Attribut)` → `Angriff Fern`;
- sonstige Angriffsboni bleiben unverändert;
- Schaden bleibt unverändert.

Die Einstellung `waffenfinesse` wird pro Angriff im Charakter gespeichert und dadurch von der bestehenden Charakter-Speicherung sowie Export/Import erfasst.

Version v0.43.0.
