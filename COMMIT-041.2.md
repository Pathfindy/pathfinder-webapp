# Commit 41.2 – Mächtige magische Fänge repariert

- Sondereffekt „Mächtige magische Fänge“ behält seine zwei bisherigen Modi:
  1. Alle Angriffe erhalten +1.
  2. Ein einzelner Angriff erhält den stufenabhängigen Bonus.
- Im Modus „Alle“ wird keine Angriffsauswahl angezeigt.
- Im Modus „Einzeln“ erscheint wieder eine einzelne Angriffsauswahl A1–A6.
- Die neue allgemeine Mehrfach-Angriffszuweisung aus Commit 41 gilt weiterhin für normale zuweisbare Effekte.
- Mächtige magische Fänge bleibt bewusst auf genau einen Angriff begrenzt.
- Berechnung korrigiert: Modus „Alle“ wirkt auf alle Angriffe; Modus „Einzeln“ ausschließlich auf den ausgewählten Angriff.
- Version v0.41.2.
