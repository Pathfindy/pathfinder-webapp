# Commit 38.2

- Kampagnen können gelöscht werden.
- Zugeordnete Charaktere gelöschter Kampagnen werden nach "Charakter ohne Kampagnenzuordnung" verschoben.
- Die Kampagne "Charakter ohne Kampagnenzuordnung" kann nicht gelöscht werden.
- Foto, Umbenennen, Effekt-Kopie und Löschen erfolgen direkt in den Charakter-Bannern des Kampagnenbaums.
- Die separate Charakterliste bleibt ausgeblendet.
- Charakter ohne ausdrückliche Kampagnenzuordnung liegen in "Charakter ohne Kampagnenzuordnung".
- Charakterexport enthält die Kampagnenzuordnung weiterhin über das komplette Charakterobjekt.
- Import übernimmt die Kampagnenzuordnung; bei alten Dateien ohne Kampagne wird eine sinnvolle Standardzuordnung verwendet.
- Hinweistext zu aktiver Kampagne ergänzt.
- Version v0.38.2.
