# Commit 51 – Reichweiteabzüge und kritischer Schaden

## Reichweiteabzüge (nur Art = Fern)
Zwischen Angriff/Schaden und Notiz erscheint eine kompakte Zeile:
- Auswahl x1 bis x10
- x1 = 0
- x2 = −2 Angriff
- x3 = −4 Angriff
- ...
- x10 = −18 Angriff

Der gewählte Abzug wird direkt in die komplette Angriffsfolge eingerechnet.

## Kritischer Treffer
In derselben Zeile stehen:
- Krit. x2
- Krit. x3
- Krit. x4

Ein Klick zeigt den kritischen Waffenschaden im Schadensfeld an.
Ein erneuter Klick auf denselben Multiplikator schaltet zurück auf Standardschaden.

Darstellung:
- kritisches Schadensfeld farblich abgesetzt
- Totenkopfsymbol im Schadensfeld
- Anzeige als z.B. 2×(1W8+4), nicht als 2W8+8, um deutlich zu machen,
  dass der normale Schaden inklusive Modifikatoren mehrfach ausgewürfelt wird.

Die Buttons vervielfachen die normale auf der Angriffskarte berechnete
Waffenschaden-Komponente. Zusätzliche Präzisions-/Sonderwürfel werden nicht
automatisch in diese Darstellung aufgenommen.
